# «Астероид-7» — дизайн кликера

Дата: 2026-08-30. Статус: согласован, ждёт план реализации.

## 1. Концепт

Браузерный инкрементальный кликер в пиксель-арте. Игрок — оператор шахты на астероиде: кликает по астероиду, добывает руду и строит цепочку переработки **Руда → Сплав → Чипы**. Чипы покупают улучшения и открывают престиж — «перелёт к новому астероиду» за **Тёмную материю**, постоянный множитель ко всему производству.

Стек: Vite + React + TypeScript + Zustand, тесты на Vitest, деплой на GitHub Pages через GitHub Actions. Язык интерфейса — русский. Название рабочее.

Вне скоупа v1: магазин за тёмную материю, лимиты складов, второй язык, звук, реальный рекламный SDK (см. §7).

## 2. Ресурсы

| id | Название | Откуда | Куда тратится |
|----|----------|--------|---------------|
| `ore` | Руда | клик, дроны, экскаваторы, лазеры | здания, ранние улучшения, плавильни |
| `alloy` | Сплав | плавильни из руды | фабрики, лазеры, средние улучшения |
| `chip` | Чипы | фабрики из сплава | поздние улучшения, порог престижа |
| `darkMatter` | Тёмная материя | престиж | не тратится; +10 % ко всему за единицу |

## 3. Здания

Стоимость k-й единицы: `base × 1.15^k` (k — уже купленных). Цена n штук при o купленных: `base × 1.15^o × (1.15^n − 1) / 0.15`. Кнопки покупки: ×1 / ×10 / max.

| id | Название | Эффект (за штуку) | Базовая цена |
|----|----------|-------------------|--------------|
| `drone` | Буровой дрон | +0,5 руды/с | 15 руды |
| `excavator` | Экскаватор | +4 руды/с | 200 руды |
| `smelter` | Плавильня | −2 руды/с → +1 сплава/с | 100 руды |
| `factory` | Фабрика микросхем | −5 сплава/с → +1 чипа/с | 500 сплава |
| `laser` | Орбитальный лазер | +40 руды/с | 3 000 сплава + 100 чипов |

Здание видно в списке, когда игрок хотя бы раз накопил 50 % его базовой цены (по каждому ресурсу цены).

## 4. Экономика и тик

Единственная функция, в которой течёт игровое время: `simulate(state, dt): GameState` в `src/game/tick.ts`. Она чистая и используется тиком, оффлайн-прогрессом, «экстренной поставкой» и тестами.

Порядок шага:
1. `ore += добыча/с × dt`, где добыча/с = Σ(здания-добытчики × их скорость × множители) — множители: улучшения, тёмная материя (`1 + 0,1 × darkMatter`), буст ×2 (§7).
2. Плавильни хотят `smelters × 2 × множители × dt` руды. Съедают `min(хотят, ore)`. `alloy += съели × 0,5 × множитель выхода`. Эффективность плавилен = съели / хотели (показывается в UI, при < 100 % — подпись «не хватает руды»).
3. Фабрики — то же со сплавом → чипами: потребление 5, выход 0,2.
4. Таймеры эффектов (`boostRemaining`, `meteorRemaining`) уменьшаются на dt. Если эффект истекает внутри шага, шаг делится на две части: с эффектом и без.

Клик: `1 × множители клика × (1 + 0,1 × darkMatter) × (метеоритный дождь ? 10 : 1)` руды.

Игровой цикл в браузере: `setInterval` 100 мс, `dt = (now − lastTick) / 1000`. Если `dt > 300 с` (вкладка была заморожена) — считаем как возвращение из оффлайна (§6). Иначе `simulate` кусками не длиннее 60 с.

| `click3` | Гравитационный захват | клик ×3 | 1 фабрика | 500 чипов |

### Престиж — «Перелёт к новому астероиду»
- Доступен, когда за текущий астероид произведено ≥ 10 000 чипов (`stats.runChips`).
- Награда: `floor(sqrt(runChips / 1000))` тёмной материи (10 000 чипов → 3).
- Каждая единица тёмной материи: +10 % к добыче, переработке и клику, навсегда.
- Сбрасывает: ресурсы, здания, улучшения, эффекты, `runChips`. Сохраняет: тёмную материю, достижения, счётчик перелётов, общую статистику.
- Спрайт астероида меняется по `prestigeCount % N` (N — сколько вариантов найдётся, §8).

### Достижения
~20 бейджей с тостом при получении, без бонусов. Категории и примеры:
- Клики: 100 / 1 000 / 10 000 («Мозоль», «Рука-бур», «Кликер-легенда»).
- Всего руды: 1 тыс / 1 млн / 1 млрд.
- Всего чипов: 100 / 10 тыс / 1 млн.
- Здания: 10 и 50 каждого типа.
- Перелёты: 1 / 5.
- Особые: «Простой» — плавильни на 0 % эффективности 60 с подряд; «Смотрящий» — 10 просмотров рекламы.

## 6. Сохранение и оффлайн

- localStorage, ключ `asteroid7:save`, JSON с полем `version`. Миграции в `save.ts` — цепочка `v1 → v2 → …`.
- Автосохранение каждые 10 с, при `visibilitychange` (hidden) и `beforeunload`.
- Экспорт — base64 от JSON, импорт — с валидацией и миграцией. Полный сброс с подтверждением. Всё в панели «Настройки».
- При загрузке: `elapsed = min(now − savedAt, 8 ч)`. Если `elapsed ≥ 60 с` — `simulate` кусками по 60 с, результат применяется сразу, показывается модалка «Пока вас не было» с приростом каждого ресурса и кнопкой «Забрать ×2» (§7).

## 7. Реклама за вознаграждение

### Абстракция
```ts
type AdPlacement = 'boost' | 'offlineDouble' | 'supply' | 'prestigeBonus' | 'meteorShower'
type AdResult = 'rewarded' | 'dismissed' | 'failed'

interface AdProvider {
  isAvailable(placement: AdPlacement): boolean
  showRewarded(placement: AdPlacement): Promise<AdResult>
}
```
Провайдер выбирается при старте в `src/ads/index.ts`. В v1 единственная реализация — `MockAdProvider`: модалка «Реклама» с обратным отсчётом 5 с; кнопка «Забрать награду» активна после отсчёта, «Закрыть» до него → `dismissed`. Награда применяется только при `rewarded`. Подключение реального SDK (Яндекс Игры, CrazyGames, AdSense H5) — новая реализация интерфейса, игра не меняется.

Применение наград — чистые функции в `src/game/rewards.ts`, кулдауны хранятся в состоянии как unix-время и переживают перезагрузку.

### Плейсменты
| id | Где | Награда | Кулдаун |
|----|-----|---------|---------|
| `boost` | кнопка «Перегрузка реактора» под астероидом | всё производство ×2 на 10 мин | 30 мин после окончания |
| `offlineDouble` | модалка «Пока вас не было» | прирост за оффлайн начисляется ещё раз | — (одна модалка — одна кнопка) |
| `supply` | кнопка «Экстренная поставка» в панели зданий | ресурсы за 30 мин текущего производства (`simulate(state, 1800)` кусками по 60 с) | 1 ч |
| `prestigeBonus` | панель «Перелёт», вторая кнопка «Перелёт с бонусом» | тёмной материи ×1,5 (`floor`) | — |
| `meteorShower` | кнопка «Метеоритный дождь» под астероидом | клик ×10 на 30 с, по экрану падают метеоры | 15 мин |

Кнопки с кулдауном показывают оставшееся время и неактивны. Если `isAvailable` → `false`, кнопка скрыта.

## 8. Визуал и спрайты

- Шрифт Press Start 2P через `@fontsource/press-start-2p`, без внешних запросов.
- Все спрайты — PNG в `src/assets/sprites/`, рендер через `<img>` или `background-image` с `image-rendering: pixelated`. Манифест `src/assets/sprites.ts` сопоставляет id → импорт.
- Источники: бесплатные паки с лицензией CC0 / CC-BY (Kenney, OpenGameArt, itch.io). Каждый файл записан в `src/assets/CREDITS.md` с автором, ссылкой и лицензией. Чего не найдётся — генерируются плейсхолдеры скриптом `scripts/placeholders.mjs` (цветной силуэт нужного размера) и вносятся в список «нарисовать» в `CREDITS.md`.

Нужные спрайты:

| id | Размер | Назначение |
|----|--------|------------|
| `asteroid-0…N` | 96×96 | астероид, варианты по перелётам (минимум 1) |
| `shard` | 8×8 | осколок при клике |
| `meteor` | 16×16 | падающий метеор в «Метеоритном дожде» |
| `building-drone`, `-excavator`, `-smelter`, `-factory`, `-laser` | 32×32 | карточки зданий |
| `res-ore`, `-alloy`, `-chip`, `-darkmatter` | 16×16 | иконки ресурсов |
| `bg-stars` | тайл 256×256 | фон (допустима CSS-генерация точек вместо файла) |
| `frame` | 9-slice 24×24 | рамка панелей (допустим CSS `border-image` или чистый CSS) |

Анимации: астероид при клике сжимается и вздрагивает (CSS transform), 3–6 осколков разлетаются и гаснут, всплывает «+N». Тёмный звёздный фон, неоновые акценты по цвету ресурса.

Раскладка: сверху панель ресурсов со скоростью в секунду; слева астероид с кнопками буста и метеоритного дождя; справа вкладки «Здания / Улучшения / Достижения / Перелёт / Настройки». На ширине < 800 px — в столбик, вкладки внизу.

## 9. Архитектура

```
src/
  game/                 чистая логика без React и без обращения к часам
    types.ts            GameState, id-типы
    content/            resources.ts, buildings.ts, upgrades.ts, achievements.ts
    economy.ts          цена n штук, скорости с множителями, эффективность
    tick.ts             simulate(state, dt)
    prestige.ts         canPrestige, darkMatterGain, applyPrestige
    rewards.ts          applyBoost, applySupply, applyMeteorShower, кулдауны
    achievements.ts     проверка условий → новые достижения
    save.ts             serialize / deserialize / migrate, offline-расчёт
    format.ts           1,2 тыс · 3,4 млн · 5,6 млрд · 7,8 трлн · далее 1.2e15
  ads/                  AdProvider, MockAdProvider, выбор провайдера
  store/                Zustand-стор: state + действия
                        click, buy, buyUpgrade, prestige, tick, watchAd(placement), load, reset
  ui/                   компоненты: App, ResourceBar, Asteroid, BuildingCard, BuildingList,
                        UpgradeList, AchievementList, PrestigePanel, SettingsPanel,
                        OfflineModal, AdModal, Toast, MeteorShower
  main.tsx
```

Состояние:
```ts
interface GameState {
  version: 1
  resources: Record<'ore' | 'alloy' | 'chip', number>
  darkMatter: number
  buildings: Record<BuildingId, number>
  upgrades: UpgradeId[]
  achievements: AchievementId[]
  prestigeCount: number
  stats: {
    clicks: number
    totalProduced: Record<'ore' | 'alloy' | 'chip', number>
    runChips: number
    adsWatched: number
    smelterIdleSeconds: number
  }
  effects: { boostRemaining: number; meteorRemaining: number }   // секунды
  cooldowns: { boostUntil: number; supplyUntil: number; meteorUntil: number } // unix ms
  savedAt: number
}
```

Правила границ: `game/` не импортирует React, Zustand и не читает `Date.now()` — время приходит параметрами. Стор — тонкая обёртка: действие вызывает чистую функцию и кладёт результат. UI подписывается на срезы стора селекторами, чтобы тик 10 раз в секунду не перерисовывал всё дерево.

## 10. Тестирование

Vitest, тесты рядом с кодом (`*.test.ts`). Ожидания — литералами.

Ядро (`game/`):
- цена 10 дронов при 0 купленных; цена при 5 купленных;
- `simulate` 1 с: 10 дронов дают 5 руды; плавильни при нехватке руды работают на 40 % и выдают ровно столько сплава, сколько позволяет руда; фабрики без сплава — 0 %;
- буст истекает внутри шага — производство делится корректно;
- престиж: недоступен при 9 999 чипов, при 10 000 даёт 3 тёмной материи, состояние сбрасывается по правилам §5;
- награды: `supply` даёт то же, что 30 мин `simulate`; кулдауны выставляются;
- достижения срабатывают один раз;
- `save`: round-trip сериализации, миграция с v1, оффлайн-расчёт кусками при 8 ч и при 9 ч (кап);
- `format`: 999 → «999», 1 234 → «1,2 тыс», 1,5e15 → «1.5e15».

UI (React Testing Library): клик по астероиду увеличивает руду; кнопка покупки неактивна без ресурсов; `MockAdProvider` — награда только после отсчёта, «Закрыть» до него не начисляет.
